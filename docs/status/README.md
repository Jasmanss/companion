# Status page

Private claude.ai page: https://claude.ai/artifact/4bpjT3BZ9AH3Shg3VWGTqX

Roadmap & design keeps it current. To change it: edit `status.json`, run `node docs/status/build.mjs`, then republish `docs/status/index.html` to the same link (Artifact tool, same file path).

Sections, in order: Waiting on you, In progress, Up next, Ideas not planned yet, Done. Each entry has a name, one line, and the date it last changed. Mark anything not checked against git or a brief file as `unconfirmed` in `tag`.
