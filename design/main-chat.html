Below are four directions that really differ, each at the real panel size (400 wide), in light and dark, over a plain or busy desktop, in the four situations: nothing going on, a chat in progress, a Visual Review waiting, and two sessions finished. Steward is the real Pill. Everything is clickable: the Ask / Auto control changes what the chat does, and hovering it explains it. The brief is docs/briefs/main-chat-redesign.md.

What makes today's panel feel off

1. Everything above the chatSession chips, banner, tray, notices, review, brief and the left-off card all stack above the log. In the empty state the chat gets what is left, and the ask box sits far below a pile of unrelated things.
2. Equal weight for everythingA Tray with nothing in it takes as much room as a card that needs you. There is no sense of "this first".
3. Three styles of small heading"Tray" is a bold heading, "Where you left off" is a card with an X, "Try:" is plain text. Chips, dots, quotes and code in the same few inches.
4. The same word four timesThe project's name is in the header chip, the session chips, the left-off title and its status line.
5. Bullets and clippingTwo bulleted lists make a glass app read like a document. The session chips scroll sideways and clip ("5m ag"), and the quote is cut off.
6. A crowded header and a dead SendA Pill, a name, five same-weight icons (two of them ways to leave) and a second row for the project. Send is a grey, lifeless button, and the one setting you change while working, Auto or Ask, is hidden in Settings.
The same in all four. No bullet points anywhere (commits, suggestions and sessions each get another form). No hide button. It leaves the header; hiding still lives in the menu bar icon's menu ("Hide from Screen Edge") and the Hide shortcut in Settings → Shortcuts, both of which exist today. Esc and the tuck arrow remain the way to put the panel away. Ask / Auto sits next to the text box, says which mode is on, and says what Auto will never do on its own.

The running-commands control

It is the same two states in all four, drawn four ways. Hover or focus it for what it means. In Ask each time every command waits for a Run click, as today. In Auto only commands Steward knows are safe run by themselves; anything it cannot read or does not know counts as risky and asks, the way isRisky works today.

What Auto runs by itselfReading and listing files, searching, git status, log and diff, and running tests, lint and typecheck in the project. A row shows "Ran automatically" with a small "auto" tag, so you can see what happened.
What always asks, even in AutoDeleting, git push, deploys and rollbacks, installing packages, and anything outside the project. The card says why ("Auto is on, but pushing always asks"), so Auto never feels like a loophole.
What changes in SettingsNothing is removed: Settings → Steward → Running commands stays, and the two stay in step. The control by the text box is the quick way, not a second setting.
Where it lives per directionA: a two-part switch inside the text box. B: a line above it with a sentence under it. C: a shield toggle in the box. D: a chip on the right of the command bar.

Where hiding goes

The eye-with-slash button is gone from the header in all four. "Hide from the screen edge" stays in the menu bar icon's menu (it switches to "Show at Screen Edge" while hidden) and as the Hide shortcut in Settings → Shortcuts. Nothing else changes about hiding.
