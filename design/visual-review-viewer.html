The note: where the words come from

(a) Claude's own wordsThe first one or two sentences of Claude's final reply. It is already in the Stop hook Steward receives (last_assistant_message, up to 4,000 characters), so nothing new is read and nothing leaves the Mac.Cost: none. Privacy: nothing sent. Weak spot: it says what Claude meant to do, so it can be wrong, vague, or a question ("Want me to...?"). Shown as "Claude says".
(b) Steward looks at the picturesThe two photos go to the Claude API and a model writes the line.Cost: a few thousand input tokens per review (two 1440 by 900 pictures), a fraction of a cent on the smallest model; not measured. Privacy: the page leaves the Mac, which breaks Visual Review's promise today that it only talks to this Mac. Needs: an API key in Steward (the chat has one if set; a Claude Code login alone does not). Says what actually shows. Shown as "Steward sees".
(c) (a) by default, (b) on a buttonRecommendedEvery card has the note from (a), free and local. A "Describe what changed" button asks for (b) for that one review, with one sentence first: "This sends the two pictures to Anthropic with your API key." The answer is kept with the review.The promise stays true by default. The picture-based note is a choice you make per review. If there is no API key, the button is not shown.

Where it fits

CaseWhat happens
The panelClick the card's picture, or "Open big". The same window grows into the big viewer, centered on the screen, up to about the work area minus 24 points all round (about 1,460 by 930 on a MacBook Pro 14: the page's 1,440 pixels at 100%). Esc or the X goes back to the panel.
In the notchThe same. The viewer is centered, so the notch only matters for how the panel comes back (it drops from the notch again).
A moved panelThe viewer is centered, ignoring where the panel was. When it closes, the panel goes back to its saved spot. Main building checks that this return does not look like a long slide; if it does, it fades and then places the panel.
An alert (Phase 2)A click opens the panel at the card, as planned. The viewer is one more click. A click on the alert could open the viewer directly later; not now.
Quiet mode, pin, step asideSame as the tray viewer today: it counts as the panel being open.
Why not a real full screenmacOS full screen is a separate Space with a slow slide, it hides the app you are reviewing, and Steward's windows do not belong in it. A big centered window gets the same pixels without leaving your desktop.
