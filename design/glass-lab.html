    Activity animations

    Each kind of step on its own, looping while it's on screen. Finished steps collapse into one quiet line you can expand. Loops use CSS keyframes and animate only transform and opacity. The blur on streaming words is a pre-blurred copy fading out, so nothing animates a filter.

    Notes for Phase 1

    • In the app, the panel's frost comes from Electron's macOS vibrancy behind a transparent page. This lab fakes it with CSS backdrop-filter over an in-page desktop, which is the only way a web page can show it.
    • The character's frost slider controls how milky its glass is. Canvas can't blur the desktop either, so in the app the blur behind the character also comes from the panel's vibrancy.
    • The ⌘K switcher and settings sidebar never stack a light translucent layer on another. The switcher uses a thick, mostly opaque fill. Chips inside the panel use a plain tinted inset with no blur.
    • Reduce motion and Reduce transparency start from your Mac's settings, and you can flip them here to preview.
