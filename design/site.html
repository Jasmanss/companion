How it's built

One person, working with several AI chats that each have one job. Nothing counts as done until it passes its checks and the checks on GitHub turn green.

An ideaWritten down as a short brief.
A designPlanned and shown before any code.
One phaseBuilt in small commits.
ChecksLint, types, tests, and a smoke run of the app.
CI is greenRun again on GitHub for every phase.
My OKOnly then does it merge.
Four chats, four rolesA front door, a designer, a builder and a researcher. They hand work to each other in written briefs.
One phase at a timeEach phase is small enough to review on its own.
More than 280 testsPlus a smoke run that launches the real app.
